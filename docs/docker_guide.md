# Запуск движка и примеров в Docker-контейнере

Контейнеризация позволяет собрать и запустить движок Huynity, интерактивные 3D/2D примеры и полный набор тестов на **любой операционной системе** (Windows, macOS, Linux) без необходимости локальной установки компиляторов, CMake, Ninja или SDL3.

Для интерактивного вывода в контейнер встроен **HTML5 noVNC веб-клиент**: графическое окно рендерится в виртуальный дисплей и транслируется в ваш веб-браузер в реальном времени с поддержкой мыши и клавиатуры на порту `6080`.

---

## 1. Быстрый старт (Любая ОС)

### Запуск через Docker Compose (Рекомендуется)

```bash
# Сборка образа и запуск интерактивного 3D-куба:
docker compose up
```

После запуска откройте браузер по адресу:
👉 **[http://localhost:6080](http://localhost:6080)**

В браузере откроется полноэкранный рабочий стол с работающим нативным окном приложения:
- **Зажмите левую кнопку мыши** и водите курсором для свободного 3D-вращения куба;
- **Зажмите Пробел** для ускорения вращения;
- **Нажмите Escape** для выхода.

## 2. Запуск конкретных примеров

### Деревня с мельницей («Windmill Village») на порту 6081
```bash
docker compose up village
```
👉 Откройте в браузере: **[http://localhost:6081](http://localhost:6081)**
- **Зажмите левую кнопку мыши** для свободного облёта камеры вокруг деревни;
- **Колёсико мыши** или клавиши W/S для плавного зума;
- **Пробел** — ускорение вращения лопастей мельницы.

### Галерея рендерера (Wireframe, Gouraud, текстурированный спрайт) на порту 6082
```bash
docker compose up gallery
```
👉 Откройте в браузере: **[http://localhost:6082](http://localhost:6082)**

### 3D-коридор от первого лица («First-Person Corridor») на порту 6083
```bash
docker compose up corridor
```
👉 Откройте в браузере: **[http://localhost:6083](http://localhost:6083)**
- **W/S** — движение вперед и назад вдоль кольцевого коридора;
- **A/D** — стрейф влево и вправо между внутренними и внешними стенами;
- **Зажмите левую кнопку мыши** и водите курсором для свободного обзора на 360° (поворот и наклон головы);
- **Пробел** — ускоренный бег по тоннелю.

### Управление ровером от третьего лица («Third-Person Arena») на порту 6084
```bash
docker compose up third-person
```
👉 Откройте в браузере: **[http://localhost:6084](http://localhost:6084)**
- **W/S** — газ вперед / задний ход ровера;
- **A/D** — поворот руля (вращение корпуса ровера);
- **Зажмите левую кнопку мыши** для свободного облёта камеры вокруг машины;
- **Пробел** — турбо-ускорение (Warp Speed).

## 3. Запуск через скрипт `docker_run.sh`

В репозитории есть удобный скрипт `./tools/scripts/docker_run.sh`, который автоматически определяет `docker` или `podman`:

```bash
# Сборка контейнера:
./tools/scripts/docker_run.sh build

# Запуск интерактивной веб-трансляции (по умолчанию Orbit Arena):
./tools/scripts/docker_run.sh web

# Запуск конкретного примера (например, hello_cube):
./tools/scripts/docker_run.sh web hello_cube

# Запуск полного набора юнит- и интеграционных тестов (53 CTest):
./tools/scripts/docker_run.sh test

# Генерация скриншота без открытия браузера (сохраняется в ./output/):
./tools/scripts/docker_run.sh screenshot hello_cube /app/output/cube.png
./tools/scripts/docker_run.sh screenshot game_scene /app/output/arena.png
```

---

## 4. Запуск юнит-тестов в контейнере

Запуск полного набора из 53 тестов CTest:

```bash
docker compose run --rm test
```
*Все тесты выполняются в изолированном контейнере с выводом подробных результатов на экран.*

---

## 5. Нативный вывод окна на Linux (X11 Forwarding)

Если вы работаете в Linux и хотите открыть нативное окно на своём рабочем столе вместо браузера:

```bash
# Разрешить локальные X11 подключения:
xhost +local:root

# Запустить пример с прямым пробросом X11 дисплея:
docker run --rm -it \
    -e DISPLAY=$DISPLAY \
    -v /tmp/.X11-unix:/tmp/.X11-unix \
    huynity:latest run game_scene --continuous
```

## 6. Структура файлов контейнеризации

- `Dockerfile` — многослойная OCI-сборка на базе `ubuntu:24.04`, компиляция SDL3 release 3.2.8 из исходников, сборка Huynity в Release-режиме, утилиты Xvfb, x11vnc, noVNC и websockify.
- `docker-compose.yml` — сервисы `web` (6080), `hello-cube` (6081), `gallery` (6082) и `test`.
- `tools/docker/entrypoint.sh` — стартовый скрипт диспетчеризации (веб-стриминг, тесты, скриншоты, нативный запуск).
- `tools/scripts/docker_run.sh` — кроссплатформенный скрипт-хелпер для Docker и Podman.
